🎯 Real-Time Object Recognition using YOLOv8 and Webcam

This project performs real-time object detection using the YOLOv8 model and a webcam feed.  
The system detects objects from live video and displays bounding boxes with labels.

---

 🚀 Features

- Real-time object detection from webcam  
- Uses YOLOv8 pretrained model (auto-downloaded)  
- Bounding boxes and labels on detected objects  
- Lightweight and fast detection  
- Press ESC to exit  

---

🧠 How It Works

1. YOLOv8 model loads automatically from Ultralytics
2. Webcam captures live video
3. Each frame is processed by YOLO
4. Detected objects are drawn with boxes and labels
5. Output displayed in real time

---

 ⚙️ Requirements

Install dependencies:

pip install ultralytics opencv-python

---

 ▶️ Run the Program

python green.py

---

⌨️ Controls

ESC → Exit detection window

---

 📦 Model

YOLOv8 Nano (yolov8n)

The model is automatically downloaded by Ultralytics on first run.  
No manual download required.
